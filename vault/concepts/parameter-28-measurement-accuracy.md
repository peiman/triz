## Overview

Engineering Parameter #28 of the [[concept-39-engineering-parameters|39 Engineering Parameters]] — the closeness of a measured value to the true value of a property. The 39 parameters form both axes of the [[concept-contradiction-matrix|Contradiction Matrix]]; a real problem is translated into them to look up [[concept-40-inventive-principles|inventive principles]].
