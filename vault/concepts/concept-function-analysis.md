## Overview

**Function Analysis** is a modern-TRIZ analytical tool that models an engineering
system as **components and the functions they perform on each other**, with each
function's usefulness and cost. Its output is a **Function Model**. (MATRIZ:
"an analytical tool that identifies functions, their characteristics, and the
cost of the system and its supersystem components.")

## Key Properties

- Each function has a usefulness category (**Useful** or **Harmful**) and, for
  useful functions, a performance level (**Normal / Insufficient / Excessive**).
- Functions are ranked **Basic / Additional / Auxiliary**; described in
  Subject–Action–Object form (a carrier acts on an object, changing a parameter).
- Goal: surface disadvantages (harmful, insufficient, excessive functions;
  excessive cost) as the input to solution tools.
- **Modern/contemporary TRIZ** (MATRIZ / Ideation / GEN3 lineage), drawing on
  Value Engineering (Miles); the classical precursor is
  [[concept-su-field-analysis|su-field analysis]].

## Connections

The function model is the direct input to [[concept-trimming|Trimming]] and
[[concept-feature-transfer|Feature Transfer]]; serves the pursuit of
[[concept-ideality|ideality]].
