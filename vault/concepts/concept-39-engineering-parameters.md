## Overview

The **39 Engineering Parameters** (also "typical parameters") are Altshuller's
generalized abstractions of the system features most often involved in
[[concept-technical-contradiction|technical contradictions]]. They form both
axes of the [[concept-contradiction-matrix|Contradiction Matrix]]: a real problem
is translated into one or more of these standard parameters in order to use the
matrix.

**Why 39:** an empirically derived set distilled from large-scale patent
analysis. Several appear as **moving vs. stationary** pairs (1–8, 15–16, 19–20),
reflecting that the physics differs for moving vs. static objects.
