## Overview

Inventive Principle #31 of the [[concept-40-inventive-principles|40 Inventive
Principles]]: make an object porous, and use the pores to carry a useful
substance.

## Sub-principles

- a) Make an object porous or add porous elements (inserts, coatings).
- b) If an object is already porous, use the pores to introduce a useful
  substance or function.

## Examples

- Drill holes in a structure to reduce weight (a).
- A porous wick storing and releasing lubricant or coolant in use (b).
