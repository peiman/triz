## Overview

A [[concept-laws-of-engineering-system-evolution|TESE trend]] (MATRIZ): "as
engineering system evolves, it develops more ways in which it can be controlled."
A sub-trend of [[trend-increasing-coordination|increasing coordination]].

## Key Properties

- **Level of control progression:** uncontrolled → fixed program → intervention to
  fixed program → externally controlled → self-control (macro-level via sensors;
  micro-level via direct material response).
- **Number of controllable states:** single → few discrete → infinitely variable
  → multiple ranges.
- Partly descends from late-Altshuller **substance-field
  ([[concept-su-field-analysis|su-field]]) involvement / controllability** ideas,
  partly a new emphasis — flagged (moderate confidence on ancestor).

## Connections
