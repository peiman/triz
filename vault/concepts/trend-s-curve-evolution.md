## Overview

A [[concept-laws-of-engineering-system-evolution|TESE trend]] (MATRIZ): "As an
engineering system evolves, the evolution of each main parameter of value (MPV)
describes an S-shaped curve in time." See also the core note
[[concept-s-curve|S-Curve of System Evolution]].

## Key Properties

- Four stages: **infancy** (idea/prototype, not yet on market), **growth**
  (intensive expansion, mass production), **maturity** (mass production reaching
  development limits), **decline** (non-utilitarian, niche, or absorbed into a
  super-system).
- A high-risk transitional phase sits between infancy→growth (lab to market entry).
- Maps to Altshuller's **Law of S-shaped evolution** (direct descendant —
  inference, not MATRIZ-asserted).

## Connections

The life-cycle envelope along which the other TESE trends act as mechanisms.
