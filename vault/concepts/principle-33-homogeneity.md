## Overview

Inventive Principle #33 of the [[concept-40-inventive-principles|40 Inventive
Principles]]: make interacting objects of the same material (or one with
identical properties).

## Sub-principles

- a) Make objects interacting with a given object out of the same material (or a
  material with identical properties).

## Examples

- Make the container of an abrasive material from the same abrasive so it isn't
  worn away differentially.
- A diamond-tipped tool to machine diamond (illustrative).

## Connections

Conceptual opposite-pair with [[principle-40-composite-materials|Composite
Materials]] (same-material vs. mixed-material).
