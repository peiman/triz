## Overview

The **System Operator** (a.k.a. 9 Windows / Multi-Screen Schema) is a classical
Altshuller thinking tool that views a system simultaneously across two axes:
**system level** (sub-system / system / super-system) and **time** (past /
present / future), producing a 3×3 grid of nine "windows." Its purpose is to
break [[concept-psychological-inertia|psychological inertia]] by preventing
single-point, single-moment thinking.

## Key Properties

- Horizontal axis = time (Past | Present | Future); vertical axis = system level
  (Super-system / System / Sub-system). The **System–Present** sits in the centre.
- The super-system is the environment/neighbours (see [[concept-super-system|
  super-system]]); the sub-system is the components; the system is the focal object.
- A systematization-of-thinking instrument, not a solution generator; the time
  axis connects to the [[concept-laws-of-engineering-system-evolution|laws of
  system evolution]] and the level axis to [[concept-resources|resource]] scanning.
- Classical (Altshuller, "thinking in time and scale"); the "9 Windows" packaging
  was popularized by later Western practitioners.
