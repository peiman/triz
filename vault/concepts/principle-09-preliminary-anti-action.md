## Overview

Inventive Principle #9 (triz.org variant: "Prior Counteraction"): pre-apply an
opposing action or stress to neutralize a future harmful effect.

## Sub-principles

- a) If an action has both harmful and useful effects, replace it with
  anti-actions that control the harm.
- b) Create beforehand stresses in an object that will oppose known undesirable
  working stresses later.

## Examples

- Buffer a solution to prevent harm from extremes of pH (a).
- Pre-stress rebar before pouring concrete (b).
