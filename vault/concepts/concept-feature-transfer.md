## Overview

**Feature Transfer** is a modern-TRIZ tool that improves a **base system** by
transferring useful features from an **alternative system** (a competing system
performing the same primary function by different means), combining the useful
features of both while avoiding their disadvantages. (MATRIZ: "transferring
certain features from the alternative system with the aim to combine the useful
features in a single system.")

## Key Properties

- **Base system** = the system being improved; **alternative system(s)** =
  comparable systems achieving the same primary function differently.
- Typically used with [[concept-function-analysis|Function Analysis]] — comparing
  functions/features across base and alternative systems identifies what to
  transfer.
- Known limitations: incomplete search of alternative systems; imprecise choice
  of which alternative to draw from.
- Modern/contemporary TRIZ (MATRIZ-codified); single-developer attribution
  unverified.

## Connections

Complements [[concept-trimming|Trimming]] (import a feature vs. remove a
component); transferring a feature often surfaces a
[[concept-technical-contradiction|contradiction]] to resolve.
