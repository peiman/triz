## Overview

**Trimming** is a modern-TRIZ tool that improves a system by **removing
components and redistributing their useful functions** to remaining system or
super-system components, while preserving performance. (MATRIZ: "removing
(trimming) certain components and redistributing their useful functions among
the remaining system or its supersystem components, while preserving quality and
performance.") It raises [[concept-ideality|ideality]] by cutting cost and harm.

## Key Properties

- Operates on the [[concept-function-analysis|Function Model]] as input.
- **Trimming rules** ask "who performs the function instead?" in a recommended
  priority (MATRIZ lists an A, X, B, C, D, E order): the function object itself
  performs it; the function is no longer needed; another existing component or
  [[concept-resources|resource]] takes it over. (Exact lettered wording beyond
  A/B/C is partially unverified — flagged.)
- **Partial trimming** redistributes only some functions.
- Modern/contemporary TRIZ (Ideation / GEN3 / MATRIZ lineage); older term
  "rejection."

## Connections

Consumes the [[concept-function-analysis|function model]]; complementary to
[[concept-feature-transfer|Feature Transfer]]; re-homes functions onto
[[concept-resources|resources]] to raise [[concept-ideality|ideality]].
