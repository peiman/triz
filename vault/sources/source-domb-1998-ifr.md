## Domb et al. — Using the Ideal Final Result to Define the Problem (1998)

A TRIZ Journal article showing how stating the [[concept-ideality|Ideal Final
Result]] reframes a problem before tool selection. Source for two worked teaching
examples in this vault: the [[case-study-chocolate-candy|chocolate-coated liqueur
candy]] and the [[case-study-rabbit-enclosure|self-feeding rabbit enclosure]].

**Citation:** Domb, E., et al. (1998). Using the Ideal Final Result to Define the
Problem to Be Solved. *The TRIZ Journal*, June 1998.
