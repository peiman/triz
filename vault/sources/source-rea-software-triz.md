## Rea — Applying TRIZ to Software Problems (2001 / 2005)

Kevin C. Rea's early work reinterpreting the 40 Inventive Principles for software,
giving software meanings such as Segmentation → modular decomposition, Prior Action
→ precompute/cache-warming, Feedback → closed-loop observability, Self-service →
self-configuring components. Rea also notes principles with **no** software analogue
(e.g. pneumatics/hydraulics, phase transitions) — a documented honesty about the
limits of the analogy.

**Citation:** Rea, K. C. (2001). *Applying TRIZ to Software Problems.* TRIZCON 2001
proceedings. See also Rea, K. (2005), *TRIZ and Software — Using Inventive
Principles*, The TRIZ Journal.
