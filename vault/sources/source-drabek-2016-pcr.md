## Drábek — Surmounting a PCR Challenge with the Contradiction Matrix (2016)

A peer-reviewed, open-access study applying the
[[concept-contradiction-matrix|Contradiction Matrix]] to a molecular-diagnostics
(PCR) problem — the rare industrial-adjacent case where the **full method is
documented**: exact parameter pair, matrix-output principle numbers, and which
were applied. Backs [[case-study-pcr-diagnostics|the PCR diagnostics case]].

**Citation:** Drábek, J. (2016). Surmounting a PCR challenge using a Contradictory
matrix from the Theory of Inventive Problem Solving (TRIZ). *SpringerPlus*, 5, 60.
DOI: 10.1186/s40064-015-1577-3 (PMC4720617).
