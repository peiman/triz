## TRIZ Power Tools (opensourcetriz.com)

A 25-year body of **free online TRIZ eBooks + teaching materials** by veteran
practitioners (David Troness and collaborators) who "solve problems on a daily
basis." A *method curriculum*, not software or data. Reviewed 2026-05-30.

**Structure — a composable Skills → Jobs model** (a strong template for an
agent-native, product-development TRIZ tool):
- **Skills** (building blocks): Working with Functions; Idealizing Useful /
  Informing / Harmful Functions; Discovering Cause; Mobilizing Function
  Resources; Resolving Contradictions; Neutralizing Harmful Functions.
- **Jobs** (product-dev lifecycle, built from skills): Discovering Markets →
  Creating Offerings → Designing & Prototyping → Reducing Offering Burdens →
  Resolving Problems → Selling/Licensing.

**Key signal — they reject the Contradiction Matrix as antiquated:** verbatim,
*"we don't use the contradiction matrix but separation principles instead"* and
*"that has been antiquated and a more useful tool is using the separation
principles, etc."* Independent corroboration of the dated-data critique in
[[concept-contradiction-matrix|the matrix note]]; modern practice favours
[[concept-function-analysis|function analysis]], causal (cause-effect chain)
analysis, [[concept-separation-principles|separation principles]], and
idealization.

**Not a data source:** no contradiction matrix, no downloads (PDFs removed as
"outdated"), no API. Materials are **copyrighted, free for personal/classroom
use only** — not redistributable in a software SSOT.

**Relevance:** validated the reframe of the `triz` CLI away from matrix-centric
toward an agent-native, guided, product-development **skills → jobs** substrate
(see [[decision-cli-service-strategy|the strategy decision]]).

**Citation:** Troness, D., et al. *TRIZ Power Tools.* opensourcetriz.com.
Retrieved 2026-05-30.
